# 🗡️ Maze Labyrinth

A top-down action maze adventure game built in **Godot Engine 4.7**. Navigate procedural mazes, battle enemy Shinobi ninjas and Samurai tanks, trigger hero abilities, collect power-ups, defeat Level 5 Shadow General Bosses, find the Golden Key, and escape the maze!

---

## 🎮 How to Download & Play

### Option 1: Download Standalone Release (Recommended)
1. Go to the [GitHub Releases Page](https://github.com/Ronak-jain-afk/maze-labyrinth/releases/tag/v1.0.0).
2. Download **`MazeLabyrinth.zip`**.
3. Extract the ZIP folder on your PC.
4. **Double-click `MazeLabyrinth.exe`** to launch and play the game directly!

---

## ⚔️ Controls & Abilities

| Action | Key / Control |
| :--- | :--- |
| **Move Hero** | `W` `A` `S` `D` or `Arrow Keys` |
| **Attack / Sword Combo** | `Spacebar` / `Left-Click` / `J` |
| **Shield Parry Stance** | `Hold Shift` / `Right-Click` / `K` |
| **Shadow Dash** | `Press E` |
| **Restart Level** | `R` |
| **Next Level** | `N` |
| **Main Menu / Pause** | `Esc` / `Q` |

## 🌟 Game Features

- **3 Playable Heroes**: Fighter, Shinobi, Samurai.
- **Hero Abilities**: Shield Parry Stance & Shadow Dash (with ghost trail FX and HUD cooldowns).
- **Power-Up Pickups**: ⚡ Speed Boots, 🧲 Coin Magnet, ⏱️ Time Freeze.
- **Hazards & Traps**: 🩸 Retractable corridor Spike Traps.
- **Exploration Puzzles**: 🔑 Golden Key dead-end spawn & 🔒 Locked Rune Exit Gate.
- **Enemies & Boss Fights**: 🛡️ Armored Samurai Tanks (3 HP) & 👹 Level 5+ Shadow General Boss Fights (10 HP, Enrage Phase, +1,000 score).
- **Visual Polish**: 📳 Dynamic Screen Shake & 👻 Dash Ghost Trails.
